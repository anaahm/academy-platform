# قائمة اختبار الواجهة

بعد النشر على GitHub Pages يتم التأكد من:

- الصفحة الرئيسية على الهاتف والكمبيوتر.
- اختيار التعليم العام/الأزهري ثم المرحلة والصف والمادة.
- فتح الدروس وتبديل فيديوهات المدرسين.
- تشغيل الاختبارات والمحاكيات.
- الكتب والملفات والفلاتر.
- المتصدرين والبث المباشر والمجتمع.
- تسجيل دخول الطالب والإحصائيات وDashboard الشخصي.
- تسجيل دخول الإدارة وجميع التبويبات.
- فتح وإغلاق القائمة الجانبية للإدارة على الهاتف.
- صفحة المدرس والمودال الخاص بإضافة المحتوى.
