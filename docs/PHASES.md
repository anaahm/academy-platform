# مراحل التطوير التالية

1. تثبيت الواجهة الجديدة ومراجعتها على الهاتف والكمبيوتر.
2. تحويل حساب المدرس من نموذج تجريبي إلى حساب حقيقي بصلاحيات مرتبطة بالصفوف والمواد.
3. إضافة دورة موافقة على محتوى المدرس: مسودة → قيد المراجعة → منشور/مرفوض.
4. فصل طبقة البيانات عن الواجهة لتسهيل الانتقال من Firebase إلى Hostinger/MariaDB لاحقًا.
5. تحسين الأمان: عدم حفظ كلمات المرور نصيًا، وعدم تخزين مفاتيح API السرية في الواجهة أو قاعدة بيانات يقرأها المستخدم.
6. تحسين الأداء وتقسيم الملفات الكبيرة تدريجيًا دون تغيير تجربة المستخدم.
