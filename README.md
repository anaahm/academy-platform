# Academy Platform

منصة تعليمية عربية قيد التطوير للطلاب في التعليم العام والأزهري.

## الرؤية

الطالب يختار نوع التعليم والمرحلة والصف والمادة، ثم يتعلم من خلال وحدات ودروس تحتوي على أكثر من شرح لأكثر من مدرس، وشرح مكتوب، وتدريبات واختبارات إلكترونية، مع متابعة تقدمه وتحفيزه على الاستمرار.

## الأدوار

- **Student**: مشاهدة الدروس، اختيار المدرس، حل الاختبارات، متابعة التقدم.
- **Teacher**: إدارة محتواه، إضافة فيديوهات واختبارات، متابعة إحصائياته.
- **Admin**: إدارة المنصة والمدرسين والطلاب والمحتوى والموافقات.

## الملفات الأساسية

- `index.html` — واجهة الطالب.
- `teacher.html` — لوحة المدرس.
- `admin.html` — لوحة الإدارة.

## خطة التطوير

1. تثبيت تجربة الطالب وتصميم الواجهة.
2. إنشاء نظام الحسابات والصلاحيات.
3. بناء لوحة المدرس وربط المدرس بالمواد والصفوف.
4. ربط المحتوى بالمدرس وإضافة دورة مراجعة قبل النشر.
5. ربط Firebase أثناء مرحلة التطوير.
6. إضافة الاختبارات والتقدم والإحصائيات.
7. اختبار النسخة مع مجموعة صغيرة من المدرسين.
8. الانتقال لاحقًا إلى Hostinger وBackend وقاعدة بيانات علائقية عند استقرار النسخة.

> هذه النسخة تطويرية، ولا ينبغي وضع أي مفاتيح سرية أو كلمات مرور داخل المستودع العام.
