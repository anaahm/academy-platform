# Academy Platform

منصة تعليمية عربية حديثة للطلاب والمدرسين والإدارة، مبنية باستخدام HTML/CSS/JavaScript وFirebase Realtime Database + Firebase Authentication.

## النسخة الرسمية

النسخة الجديدة أصبحت موجودة مباشرة في جذر المشروع، ولم يعد مجلد `v3/` هو النسخة المستخدمة.

### الصفحات

- `index.html` — الصفحة العامة + التسجيل + Dashboard الطالب
- `explore.html` — استكشاف جميع المراحل والصفوف والمواد
- `subject.html` — صفحة المادة والوحدات والدروس
- `lesson.html` — الفيديو، اختيار المدرس، الشرح، التدريب، المرفقات، حفظ الدرس
- `search.html` — بحث موحد في الدروس والاختبارات والملفات
- `profile.html` — ملف الطالب، الإحصائيات، الإنجازات، المحفوظات، إعدادات المرحلة
- `teacher.html` — بوابة المدرس وإرسال المحتوى للمراجعة
- `admin.html` — لوحة الإدارة الجديدة بالكامل
- `assignments.html` — مركز واجبات الطالب
- `planner.html` — مخطط المذاكرة
- `weekly-report.html` — التقرير الأسبوعي
- `schedule.html` — الجدول والمواعيد الذكية

## أهم المميزات الحالية

- إنشاء حساب مباشر بالبريد وكلمة المرور
- تخصيص المرحلة والصف لكل طالب
- Dashboard شخصية

- حفظ آخر درس والمتابعة من نفس النقطة
- حفظ الدروس للمراجعة
- أكثر من مدرس للدرس الواحد
- اختبارات داخل الدرس واختبارات مستقلة
- استكشاف كل المراحل بدون تغيير مرحلة الطالب
- بحث موحد
- إدارة المدرسين وصلاحيات المواد والصفوف
- Workflow مراجعة محتوى المدرس قبل النشر
- إدارة الطلاب والمناهج والدروس والاختبارات والملفات
- إعلانات داخل المنصة
- PWA قابلة للتثبيت
- نظام الواجبات: إنشاء من المدرس، تسليم من الطالب، تصحيح ودرجة وتعليق
- مخطط مذاكرة شخصي بمهام وأولويات وأهداف أسبوعية
- تقرير أسبوعي ذكي يقارن الأداء بالأسبوع السابق
- جدول حصص ومواعيد ذكي يجمع الحصص والبث ومهام المذاكرة
- ملاحظات خاصة داخل كل درس
- توصيات دراسية حسب أضعف مادة في تقدم الطالب
- إعداد Firebase موحد في `assets/firebase-config.js`

## Firebase

المشروع يستخدم:
- Authentication للحسابات
- Realtime Database للمحتوى والتقدم والصلاحيات

ملف `firebase.rules.production.json` يحتوي قواعد أمان مقترحة للبنية الجديدة. يجب مراجعتها واختبارها قبل تطبيقها على قاعدة البيانات الفعلية.

> ملاحظة: محتوى `lessons/quizzes/files` مقروء للعامة حاليًا حتى تعمل صفحات الاستكشاف قبل تسجيل الدخول. إذا أردنا Drafts خاصة تمامًا، الأفضل فصل المحتوى غير المنشور في مسار مستقل بدل الاعتماد على `isHidden` فقط.

1. اختبار إنشاء الحساب وتسجيل الدخول على الموبايل والكمبيوتر.
2. مراجعة قواعد Firebase وتطبيقها بعد الاختبار.
3. إضافة أول مجموعة حقيقية من المواد والدروس.
4. تجربة حساب مدرس كامل من الإرسال حتى اعتماد الإدارة.

## مراكز الطالب الاحترافية

النسخة الحالية تحتوي صفحات مستقلة بدل تكديس كل شيء داخل Dashboard:

- `exam-center.html` — مركز الاختبارات، الفلاتر، وسجل النتائج.
- `simulations.html` — محاكيات امتحان متعددة المواد بزمن وXP.
- `progress.html` — تحليلات التقدم، النشاط الأسبوعي ووقت الدراسة.
- `leaderboard.html` — ترتيب يومي/أسبوعي/شهري/كل الوقت.
- `library.html` — مكتبة الملفات والمذكرات حسب المرحلة والمادة.
- `live.html` — جلسات YouTube وZoom المباشرة والقادمة.
- `community.html` — منتدى تعليمي ومجموعات دراسة بدون رسائل خاصة.
- `search.html` — بحث موحد في الدروس والاختبارات والملفات.

## التتبع والتحليلات

- `assets/activity-tracker.js` يجمع دقائق الدراسة الفعلية عندما تكون الصفحة ظاهرة ونشطة، ويكتبها على دفعات لتقليل عمليات Firebase.
- `contentAnalytics/<lessonId>` يحتوي إحصائيات مجمعة مثل المشاهدات، إكمال الدرس ومحاولات التدريب. لا تعرض بوابة المدرس أسماء الطلاب.
- `leaderboardV3` هو نظام الترتيب الجديد ويستخدم مفاتيح يومية وأسبوعية وشهرية و`allTime`.
- الدروس المحفوظة للمراجعة موجودة داخل `studentProfilesV3/<uid>/bookmarks`.

## إدارة المحتوى V3

لوحة `admin.html` تدعم حاليًا:

- إضافة وتعديل وحذف المواد والوحدات المخصصة.
- إضافة وتعديل الدروس مع أكثر من مدرس/فيديو في الدرس الواحد.
- إضافة وتعديل وحذف الاختبارات.
- إضافة وتعديل وحذف الملفات.
- إضافة وتعديل وحذف وإظهار/إخفاء المحاكيات.
- إضافة وتعديل وحذف جلسات البث.
- إدارة المدرسين وإسناد المواد والصفوف.
- مراجعة محتوى المدرسين قبل النشر.
- مراجعة المنتدى والبلاغات وإنشاء مجموعات الدراسة.
- متابعة الطلاب والإعلانات والإعدادات.

## المجتمع والخصوصية

المجتمع مصمم للتفاعل التعليمي العام فقط. لا توجد رسائل خاصة بين الطلاب داخل المنصة. يدعم:
- الإعجاب مرة واحدة لكل حساب.
- الإبلاغ عن منشور للإدارة.
- مجموعات دراسة يمكن الانضمام إليها أو مغادرتها.
- أدوات إشراف للإدارة.

## PWA والتحديثات

`sw.js` يستخدم Network First لملفات JS/CSS والتنقل، حتى لا تعلق الأجهزة على نسخة قديمة بعد نشر تحديث. الوسائط الثابتة فقط تستخدم Cache First.
