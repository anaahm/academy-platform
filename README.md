# Academy Platform

منصة تعليمية عربية حديثة للطلاب والمدرسين والإدارة، مبنية باستخدام HTML/CSS/JavaScript وFirebase Realtime Database + Firebase Authentication.

## النسخة الرسمية

النسخة الجديدة أصبحت موجودة مباشرة في جذر المشروع، ولم يعد مجلد `v3/` هو النسخة المستخدمة.

### الصفحات

- `index.html` — الصفحة العامة + التسجيل + Dashboard الطالب
- `explore.html` — استكشاف جميع المراحل والصفوف والمواد
- `subject.html` — صفحة المادة والوحدات والدروس
- `lesson.html` — الفيديو، اختيار المدرس، الشرح، التدريب، المرفقات، حفظ الدرس
- `search.html` — بحث موحد في الدروس والاختبارات والملفات
- `profile.html` — ملف الطالب، الإحصائيات، الإنجازات، المحفوظات، إعدادات المرحلة
- `teacher.html` — بوابة المدرس وإرسال المحتوى للمراجعة
- `admin.html` — لوحة الإدارة الجديدة بالكامل

## أهم المميزات الحالية

- إنشاء حساب مباشر بالبريد وكلمة المرور
- تخصيص المرحلة والصف لكل طالب
- Dashboard شخصية
- XP ومستويات وStreak وإنجازات
- حفظ آخر درس والمتابعة من نفس النقطة
- حفظ الدروس للمراجعة
- أكثر من مدرس للدرس الواحد
- اختبارات داخل الدرس واختبارات مستقلة
- استكشاف كل المراحل بدون تغيير مرحلة الطالب
- بحث موحد
- إدارة المدرسين وصلاحيات المواد والصفوف
- Workflow مراجعة محتوى المدرس قبل النشر
- إدارة الطلاب والمناهج والدروس والاختبارات والملفات
- إعلانات داخل المنصة
- PWA قابلة للتثبيت
- إعداد Firebase موحد في `assets/firebase-config.js`

## Firebase

المشروع يستخدم:
- Authentication للحسابات
- Realtime Database للمحتوى والتقدم والصلاحيات

ملف `firebase.rules.production.json` يحتوي قواعد أمان مقترحة للبنية الجديدة. يجب مراجعتها واختبارها قبل تطبيقها على قاعدة البيانات الفعلية.

> ملاحظة: محتوى `lessons/quizzes/files` مقروء للعامة حاليًا حتى تعمل صفحات الاستكشاف قبل تسجيل الدخول. إذا أردنا Drafts خاصة تمامًا، الأفضل فصل المحتوى غير المنشور في مسار مستقل بدل الاعتماد على `isHidden` فقط.

## النسخة القديمة

تم حفظ النسخة السابقة بالكامل قبل التنظيف في الفرع:

`legacy-backup-2026-09-18`

يمكن الرجوع إليه عند الحاجة، بينما `main` يحتوي النسخة الجديدة الرسمية فقط.

## التشغيل

المشروع Static ويمكن تشغيله على GitHub Pages أو Hostinger. الصفحة الرئيسية:

`https://anaahm.github.io/academy-platform/`

## ملاحظات قبل الإطلاق العام

1. اختبار إنشاء الحساب وتسجيل الدخول على الموبايل والكمبيوتر.
2. مراجعة قواعد Firebase وتطبيقها بعد الاختبار.
3. إضافة أول مجموعة حقيقية من المواد والدروس.
4. تجربة حساب مدرس كامل من الإرسال حتى اعتماد الإدارة.
5. بعد استقرار النسخة، نقلها إلى `academy.egtaz.online`.
